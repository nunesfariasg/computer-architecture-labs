# Computer Architecture Labs

Software laboratories and simulations developed to complement the study of computer architecture and organization through practical experiments.

## Reference

TANENBAUM, Andrew S.; AUSTIN, Todd. *Structured Computer Organization*. 6th ed. Pearson, 2013.

## Objective

To explore fundamental computer architecture concepts through small implementations, simulations, and experiments.

## Topics

- Digital logic
- CPU organization and instruction execution
- Assembly language
- Memory organization and virtual memory
- Cache memory

This repository is for educational purposes and is developed alongside the study of the reference book.
